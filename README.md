# Retail Business Performance & Profitability Analysis

## Project Overview
This project analyzes retail sales data to understand business performance, profitability, sales trends, and customer segments. The dashboard provides useful insights into sales, profit, order volume, product categories, and regional performance using Power BI.

## Objectives
- Analyze overall retail sales and profit.
- Identify sales performance across product categories.
- Compare profit across different regions.
- Analyze monthly sales trends.
- Understand sales across customer segments.
- Create an interactive dashboard for business insights.

## Tools Used
- **Power BI Desktop** – Data visualization and dashboard creation.
- **Microsoft Excel / CSV** – Dataset storage and data preparation.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Creating measures and KPIs.

## Dashboard Features
- **Total Sales:** Displays overall sales revenue.
- **Total Profit:** Displays total business profit.
- **Total Orders:** Shows the number of distinct orders.
- **Total Quantity:** Displays the total quantity of products sold.
- **Sales by Category:** Compares sales across product categories.
- **Profit by Region:** Analyzes profit across different regions.
- **Monthly Sales Trend:** Shows sales performance over time.
- **Sales by Customer Segment:** Compares sales across customer segments.

## Interactive Filters
The dashboard includes slicers for:
- Region
- Category
- Segment

These filters help users interactively explore the sales data.

## Steps Involved
1. Imported the retail sales dataset into Power BI.
2. Cleaned and transformed the data using Power Query.
3. Created KPI measures using DAX.
4. Designed charts and visualizations.
5. Added interactive slicers.
6. Formatted and arranged the dashboard for better readability.

## Conclusion
This project helps understand retail business performance through interactive data visualization. It provides insights into sales, profitability, regional performance, product categories, and customer segments, helping users explore and analyze business data effectively.
